# Stage 2 — HTTPS & SSL/TLS

## Objective

Determine whether a website uses HTTPS and inspect its SSL/TLS certificate.

## What I Built

- HTTPS detection
- SSL/TLS connection
- Certificate retrieval
- Certificate expiration check
- Certificate issuer information

## What I Learned

### HTTPS

HTTPS encrypts communication between a client and a website using TLS.

### SSL/TLS Certificates

Certificates help establish the identity of a website and enable secure TLS connections.
