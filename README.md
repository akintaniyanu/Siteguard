# SiteGuard 🛡️

A simple website security checker built while learning cybersecurity.

## Why I Built SiteGuard

Most people visit websites without knowing how secure they actually are.

I wanted to build a simple tool that could perform basic website security checks and present the results in a way that is easy to understand.
